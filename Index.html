상품팀 판촉 종합 가이드

사번과 비밀번호를 입력하면 이번 기간 판촉이 바로 열립니다.

홈 화면에 앱으로 추가하기 홈 화면에 추가하면 주소창 없이 앱처럼 전체화면으로 열리고, 아이콘도 집중모델 가이드 전용 아이콘으로 표시됩니다.
ㆍ 안드로이드(크롬·삼성인터넷) — 우측 상단 ⋮ → "홈 화면에 추가"
ㆍ 아이폰(사파리) — 하단 공유 버튼 → "홈 화면에 추가"

비밀번호 설정

사번마스터에서 확인된 사번입니다. 사용하실 비밀번호를 설정해 주세요.

비밀번호 재설정 요청

보안을 위해 비밀번호를 즉시 바꿔드리지 않습니다. 계정 삭제를 요청하면 상품기획G가 확인 후 삭제하며, 이후 사번으로 다시 가입해 비밀번호를 새로 설정하시면 됩니다.

처리 절차 1. 본인이 삭제 요청 접수
2. 상품기획G가 내역 확인 후 계정 삭제
3. 사번으로 재가입 → 비밀번호 새로 설정

대외비 자료입니다. 조회 화면에는 성명·사번·지점·접속일시가 표시되며 열람 기록이 남습니다.
캡처·전달 시 출처가 그대로 확인됩니다.
